# PDF fonts

`ZhuqueFangsong-Regular.ttf` is the existing primary font for Chinese report text.

`NotoSansSymbols-Regular.ttf` supplies glyphs missing from the primary font,
including circled numbers such as ①②③. Fonts used in a report are embedded in the
PDF; generation does not require fonts installed on the server or client.

Noto Sans Symbols is licensed under the SIL Open Font License 1.1, included in
`OFL-NotoSansSymbols.txt`. The font is an unmodified copy from
[notofonts/noto-fonts](https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSansSymbols/NotoSansSymbols-Regular.ttf),
Git blob `443ca5e0969742a263c9fe77952f1a8c036f82ea`.
